# ASP.NET Core MVC Master Detail Project

A Master-Detail order management system built with ASP.NET Core MVC.

## Technologies

- ASP.NET Core MVC (.NET 9)
- Entity Framework Core 9
- SQL Server
- Bootstrap
- JavaScript
- Repository Pattern
- DTO Pattern
- Application Service Layer

## Features

- Manage Orders
- Create orders with multiple order details
- Manage Customers
- Manage Sellers
- Manage Products
- Edit and update orders
- Calculate order total price

## Architecture

The project follows a layered architecture:

- Controllers
- Application Services
- DTOs
- Repository Layer
- Domain Models
- Entity Framework Core

## Database

SQL Server is used as the database engine.
